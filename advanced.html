資料庫工作坊｜進階包

課堂上那三個動作已經夠用，這四條不急。前三條回去自己就能試，不用申請、不用錢；第四條要走公司管道，原因寫在第四頁。

① QUERY：一句話查一張表

試算表內建的函式，不用寫程式。我們的「查詢」分頁，背後就是它。

查詢句只有四個字

字意思
select要哪幾欄
where條件
order by怎麼排
limit只要前幾筆
=QUERY(資料!A:D, "select A,B,C where B contains '颱風' order by A desc", 1)

三個最常卡的

  • 欄位要用 A、B、C，不能用中文欄名
  • 文字條件用單引號：contains '颱風'
  • 最後那個 1 是「第一列是欄位名」，漏掉會被當成資料

② filter 和 reduce：用程式挑資料

Apps Script 裡最常用的兩個動作。看得懂這兩個，大部分的程式都看得懂。

  • filter：從一堆裡面挑出符合條件的
  • reduce：把一堆數字全部加起來
const 命中 = 資料.filter(r => String(r[1]).includes('颱風'));
Logger.log(命中.length + ' 則');

貼進 Apps Script，函式選這一個，按執行，看下面的「執行記錄」。

提醒：r[1] 是第 2 欄（從 0 開始數）。欄位順序改了，這個數字也要改——這就是課堂上說「欄位要固定」的原因。

③ clasp：不用複製貼上

在自己電腦上改程式，一行指令推上 Google。要有 Node.js 22 以上、會開終端機。

npm install -g @google/clasp
clasp login
clasp clone-script 〈專案 ID〉
clasp push

安裝完、登入前，要先到 script.google.com/home/usersettings 打開「Google Apps Script API」。專案 ID 在 Apps Script 編輯器左邊的「專案設定」。

三個注意

  • clone-script 是新版指令，舊版叫 clone，兩種都能用
  • 登入憑證存在你的使用者資料夾，不要上傳或給別人
  • push 會覆蓋線上版本，改之前先 pull

④ AI 幫每一列補一個欄位

多開一欄，讓 AI 一列一列填：一句話摘要、正面負面、或從一段文字抽出金額和截止日。最後這個最有價值——原本只能讀的東西，變成可以排序、篩選、加總。

為什麼今天不教

  • 要申請金鑰、要綁付款，多數人會卡在這一步
  • 每一列都要送一次，量大會慢也會產生費用
  • 同一筆跑兩次答案可能不一樣，跟資料庫「結果要穩定」衝突
  • 跟課堂那條「機敏資料不要貼進 AI」牴觸

想做的話：填 AI 需求申請單 m.aiurl.tw/5qrdo，寫清楚要補哪一欄、資料有沒有機敏內容、多久跑一次。

不管誰做都守這條：AI 產出的先寫進「暫存」分頁，人看過再併回正式表。
